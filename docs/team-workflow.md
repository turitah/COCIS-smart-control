# Team workflow

## Suggested branch names
- `feature/entrance-rfid` — Member 1 / leader
- `feature/room1-lighting` — Member 2
- `feature/room2-lighting` — Member 3
- `feature/communication-storage` — Member 4
- `feature/schedule-admin-tests` — Member 5

## Definition of done
A task is done only when:
1. Code is committed to its branch.
2. The member explains the implementation.
3. A test/demo is performed and the result recorded.
4. The integration owner reviews the change.
5. The pull request is merged after review.

## Daily update
Each member reports: completed, evidence, next task, blocker.
